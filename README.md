# لوحة التحكم — تطبيقات الأنفال

لوحة واحدة لإدارة منتجات/عروض كل التطبيقات (الدلالة للسيارات، الجوالات، السوبرماركت، العقارات).

- كل تطبيق له مستودعه وملف بياناته (data.js).
- التعديل هنا ثم «نشر الآن» يكتب الملف في المستودع مباشرة عبر GitHub API.
- رمز الدخول يحمي الشاشة، ومفتاح النشر (توكن GitHub) محفوظ في متصفح المالك فقط.
